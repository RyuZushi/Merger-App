1) File Sync
    Once connected the files within selected folders with copy into all other computers linked to said file. Specific settings can be adjusted within the UI
2) Remote file deletion
    Through the UI you are able to explore within the folders linked in Merger and select what's not shared and removed.
3) Connection outside LAN
    Merger can connect to you if it's set up properly outside your home network.
4) Easy to understand and use UI
    Easy to read buttons and mouse works, instead of just commands lines that would be confusing for some. With some customizing abilities
5) File change Log
    Button and command lets you see what files were changed, by who and when.
