1) File Sync:
    1) Once connected the files within selected folders with copy into all other computers linked to said file. Specific settings can be adjusted within the UI.
2) Remote file deletion:
    1) Through the UI you are able to explore within the folders linked in Merger and select what's not shared and removed.
3) Connection outside LAN:
    1) Merger can connect to you if it's set up properly outside your home network.
4) Easy to understand and use UI:
    1) Easy to read buttons and mouse works, instead of just commands lines that would be confusing for some. With some customizing abilities.
5) File change Log:
    1) Button and command lets you see what files were changed, by who and when.
