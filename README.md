# Merger-App-
Documentation for "Merger" Application

“Merger” is an automatic syncing software to make sure local files show up in other devices. People who would use this are people who travel or at least change computers a lot, such as a student or a employee with a laptop and a PC who doesn’t want to keep uploading them manually. You decide what folders get shared with that computers. Time saved by having this run in the background instead of stopping all work to move files over.
